FAQ

Systemfragen.

Ist SeasonCrew eine Ticketbörse?

Nein. SeasonCrew organisiert bestehende Dauerkarten innerhalb einer privaten Crew.

Können mehrere Personen verwalten?

Ja. Rollen und Berechtigungen ermöglichen gemeinsame Administration.

Kann ich Zahlungen dokumentieren?

Ja. Der Zahlstatus kann direkt bei den jeweiligen Karten gepflegt werden.
