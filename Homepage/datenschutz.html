4. Early-Access-Formular

Auf der Website befindet sich derzeit ein Eingabefeld für eine E-Mail-Adresse zur Vormerkung für den Early Access.

In der derzeit veröffentlichten technischen Version wird die eingegebene E-Mail-Adresse nicht an unseren Server übertragen und nicht dauerhaft von uns gespeichert. Die Verarbeitung findet lediglich lokal im Browser statt; nach der Anzeige der Bestätigung wird das Formular zurückgesetzt.

Sobald eine tatsächliche Early-Access-Registrierung mit Speicherung oder Versand eingerichtet wird, wird diese Datenschutzerklärung vor Inbetriebnahme entsprechend ergänzt.
