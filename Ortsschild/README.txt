ORTSSCHILD & KENNZEICHEN DESIGNER

Enthalten:
- Deutsches Ortsschild
- Deutsches Kennzeichen einzeilig
- Deutsches Kennzeichen zweizeilig
- SVG-Export
- PNG-Export mit 150, 300 oder 600 DPI

Start:
1. ZIP entpacken.
2. index.html per Doppelklick öffnen.
3. Kein Server erforderlich.

Schriften:
Ortsschilder:
- Bahnschrift
- DIN Alternate
- Arial

Kennzeichen:
- Bahnschrift Condensed
- Arial Narrow
- DejaVu Sans Condensed
- Liberation Sans Narrow

Es wird automatisch die erste auf dem Gerät verfügbare Schrift genutzt.

Änderung Soll-Stand:
- Mehrzeilige Texte oben/unten bleiben erhalten.
- Schriftgröße weiterhin je Zeile individuell einstellbar.
- Roter Ortsausgangsbalken wieder wie im ursprünglichen Designer: feste Geometrie und hinter dem unteren Text.

Update 2026-08-28:
